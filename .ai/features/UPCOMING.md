# Upcoming features

Features whose spec is written and approved, parked while another feature is current. Brainstorm several with `/sdd:po`, then pick one at a time to implement.

**Rules**
- A feature enters this list when its spec is approved and the current feature moves to another one.
- It leaves when it becomes the current feature again; when it is completed, it is never listed.
- One entry per feature, newest last: folder, what it does in one line, where it stopped.

**Where it stopped**: `spec approved` (no tasks yet), `tasks ready` (`/sdd:prep` done), or `in progress` (some tasks done; say what is left).
